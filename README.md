# Flacual

`Flacual` is a simple TUI for interacting with `metaflac`.

## Usage

To use `Flacual`, clone the repository and then run via. `uv`:

`uv run main.py`

`Flacual` can also be run in `dev` mode via. the base library, [Textual](https://textual.textualize.io/):

`uv run textual run --dev main.py`

A Textual console can then be attached via. `uv run textual console`.
